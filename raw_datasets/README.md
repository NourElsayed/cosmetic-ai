Raw Datasets

This folder contains the original datasets used by the Cosmetic AI project.

The original dataset files are kept locally and are not uploaded to GitHub because of their size and dataset-specific usage restrictions.

1. CelebAMask-HQ

Purpose: Face parsing and facial-region segmentation. In this project it supports facial component mask information.

Source:
https://mmlab.ie.cuhk.edu.hk/projects/CelebA/CelebAMask_HQ.html

Local structure:

CelebAMask-HQ/
├── CelebA-HQ-img/
├── CelebAMask-HQ-mask-anno/
├── CelebA-HQ-to-CelebA-mapping
├── CelebAMask-HQ-attribute-anno
├── CelebAMask-HQ-pose-anno
└── README

Annotations: Facial component segmentation masks, attribute annotations, pose annotations, and mapping information.

The official page describes 30,000 high-resolution face images and manually annotated 512×512 masks for 19 facial component/accessory classes. The dataset is for non-commercial research use.

2. FaceSynthetics

Purpose: Synthetic facial images with ground-truth annotations for face-analysis research. In this project it is relevant to landmark and segmentation-related preprocessing/research.

Source:
https://github.com/microsoft/FaceSynthetics

Dataset page:
https://microsoft.github.io/FaceSynthetics/

Local structure:

FaceSynthetics/
├── 000000
├── 000000_ldmks
├── 000000_seg
├── 000001
├── 000001_ldmks
├── 000001_seg
└── ...

Annotations: 70 facial landmarks and per-pixel semantic segmentation labels.

The official Microsoft repository describes 100,000 synthetic face images at 512×512 resolution with 70 landmark annotations and per-pixel semantic labels. It is released for non-commercial research.

3. FFHQ

Purpose: Main source of natural face images used as Before images in the synthetic before/after pipeline.

Source:
https://github.com/NVlabs/ffhq-dataset

Local copy: The project currently contains a local subset of the official dataset.

Annotations / metadata: The official distribution includes metadata associated with the images.

The official FFHQ repository describes 70,000 PNG face images at 1024×1024 resolution. The dataset is distributed under CC BY-NC-SA 4.0 and is not intended for development or improvement of facial-recognition technologies.

4. SCUT-FBP5500

Purpose: Beauty-score research and facial landmark information. In this project it is reserved mainly for the later Beauty Score stage.

Source:
https://github.com/HCIILAB/SCUT-FBP5500-Database-Release

Local structure:

SCUT-FBP5500/
├── facial landmark/
├── Images/
├── train_test_files/
├── All_Ratings
├── Images_Sources
└── README

Annotations: 86 facial landmarks, beauty ratings, image-source information, and train/test split files.

The official repository describes 5,500 frontal faces with beauty scores and 86 facial landmarks. The dataset is for non-commercial research use.

Role in the project

CelebAMask-HQ: facial segmentation and target-mask information.

FaceSynthetics: synthetic faces, landmarks, and segmentation annotations.

FFHQ: natural Before-face images.

SCUT-FBP5500: facial landmarks and later Beauty Score evaluation.

Data handling

Original dataset files are not modified.

Large original images are not committed to GitHub.

Dataset metadata and project documentation are kept in the repository.

The local inventory is generated by scripts/build_dataset_inventory.py.

The inventory describes the local copies available on the project machine; it does not replace the official dataset releases.
