# Cosmetic AI

An AI-powered deep learning framework that simulates plastic surgery outcomes. The system takes a "Before" facial image from the user and generates a realistic "After" prediction based on the selected cosmetic procedure.


## Supported Procedures

- **Rhinoplasty**
- **Chin Augmentation**
- **Jawline Contouring**
- **Facelift**
- **Blepharoplasty** 
- **Lip Enhancement**
